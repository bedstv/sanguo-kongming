# 三國戰策：孔明篇

[開始三章旅程](https://bedstv.github.io/sanguo-kongming/?v=12.3)

V12.3 正式首頁包含完整三章：新野出發、隆中問策、城鎮整備、野外遭遇、博望先鋒與五對五決戰、結尾和存檔接續。第二章「長坂護民」加入南撤集結、兩路百姓救援、曹純追擊與四回合守橋渡河。第三章「赤壁風起」加入孫劉盟約、東風與火船雙路準備、連環艦決戰及江陵結尾。角色、肖像、動畫與 FX 沿用已獲使用者接受的 V12 對戰畫面，新增原創探索地圖、NPC 及城鎮／旅途配樂。

按「開始旅程」進入，使用方向鈕或任務「路標」探索；「軍勢／整備」管理武將、物品、裝備與陣型。進度自動保存，重新開啟可選「繼續旅程」。第一章通關後按「續章」接續第二章，原有角色、裝備與金錢都會保留。第二章通關後同樣按「續章」前往第三章。目前可完整遊玩三章。
