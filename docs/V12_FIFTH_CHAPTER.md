# V12.5 — 江陵守望

第五章接續 V12.4.1 的長沙通關存檔。此章為原創遊戲戲劇改編，並非史實戰役重建。

完整流程：長沙續章 → 江陵回防軍議 → 江陵北岸探索 → 烽火臺與北岸糧隊接應（任選先後）→ 城門軍令 → 曹仁、徐晃、張郃、魏軍槍兵與弓手五對五決戰 → 江陵安民軍府。

使用原有五將、裝備、陣型、金錢、軍糧與傷勢，維持原存檔鍵。stage 20–24 將前章完成旗標視為最低進度，避免讀檔退回 19。防守準備使用獨立 defensePlans。糧隊成功補給兩份軍糧；兩路完成後，決戰每名敵軍攻擊減 12。此效果只套用於建立新戰鬥，checkpoint 保留實際攻擊與傷勢，避免重複扣值。決戰戰敗扣 120 金，回防營地恢復六成五兵力並保留準備。通關後安民軍府保留軍需、醫者與整備。

先產生章節概念 mockup，再製作獨立江陵 production 背景，人物、文字與 UI 由既有 renderer 繪製。復用已接受的角色八姿勢 sprites、肖像及探索圖集，保留 V12.4.1 的高解析度文字、放大人物與低干擾地面。沒有聲稱新增武將或全部世界地圖完成。
