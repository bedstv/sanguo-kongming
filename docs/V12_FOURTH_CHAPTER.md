# V12.4 — 荊南定策

三章版本交付後，使用者要求繼續。本批接續第三章通關存檔，完成江陵軍議、桂陽護糧、長沙交涉、黃忠決戰與安民結尾。劇情與遭遇為本遊戲原創戲劇改編，不是歷史戰役重建，也不宣稱全三國篇完成。

## 完整旅程

1. 江陵軍議：第三章完成後按「續章」，保留五將、兵力、策略、等級、裝備、物品、陣型與金錢。與孔明交談取得護糧軍令。
2. 荊南古道：新的山城／秋林探索區，沿路可遇地方巡兵。桂陽糧站與長沙城門有劇情門檻，不能提前越過。
3. 桂陽糧站：接應糧官、擊退截糧軍，取得兩份軍糧與已保存的護糧旗標。完成後不重複獲得獎勵。
4. 長沙城門：護糧完成後與黃忠交涉，使用獨立肖像與白鬚弓將造型；交涉後進入五對五城門決戰。
5. 長沙安民：黃忠承認五將保全民眾的誠意。結尾後可在長沙軍府購買、整備與恢復，存檔可重新載入。

戰敗扣 120 金，恢復六成五兵力與全部策略，退回本章江陵軍議營地。保留護糧旗標、物品消耗與章節階段，支援下令 checkpoint。已完成章節旗標不得將第四章進度降回前章。
