# V12.2 — 長坂護民

第一章完整交付後，使用者再次指示「請繼續」。本批接續一個完整第二章，範圍為南撤集結、兩路救援、守橋渡河與江夏安民。Repository 原先沒有第二章劇本；這是本遊戲的原創戲劇改編，不宣稱具名武將配置或事件順序是歷史復原。

## 完整流程

第一章通關後，探索畫面的「續章」或「軍勢 → 軍議 → 前往第二章」可開始。保留原有兵力、策略、等級、裝備、物品、陣型與金錢，沿用同一存檔位置。

1. **南撤營地**：開場軍議，軍需商店與醫者／客棧；民長集結需要兩份軍糧，不足時可購買或在南境迎擊追兵賺取軍需。軍糧只發放一次。
2. **荊州南境／長坂古道**：穿過河橋，分別接應西路糧車與東路傷者。每路有獨立戰鬥與完成旗標，可先後救援，途中存檔接續。
3. **當陽渡口**：兩路百姓接應後才開放渡口軍令。曹純、張郃與魏軍槍／弓兵追至，五將必須守住四回合；防禦、補給與計策皆可使用。
4. **江夏營地**：第四回合敵軍反擊結束後，只要我軍仍有人存活即可達成渡河目標，敵軍不必全滅。全軍潰敗優先判定失敗。勝利後接續結尾與江夏休整，章節完成和獎勵只保存一次。

戰敗回南撤營地，保留已救援的百姓與劇情階段，付出 120 金並恢復六成五兵力。醫者／客棧可免費恢復全隊，整備後可重返渡口。軍議的休整目的地隨章節改變。
