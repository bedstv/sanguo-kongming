# V12.3 — 赤壁風起

使用者在兩章版本交付後指示繼續。本批完成一個可從第二章存檔接續的第三章：孫劉盟約、觀風與火船準備、赤壁連環艦決戰、江陵安定。具名武將與遭遇為本遊戲的戲劇改編，並非歷史戰役復原；不宣稱全三國篇已完成。

## 完整旅程

第二章通關後，在探索畫面按「續章」，或軍勢 → 軍議 → 前往第三章。保留兵力、策略、等級、裝備、物品、陣型與金錢，沿用同一個自動存檔。

1. 江東水寨：與周瑜締結盟約；軍需所與客棧／醫者可購買、配備與恢復。
2. 赤壁江岸：沿江探索，途中可能遭遇魏軍巡邏。盟約之前無法進入任務地點；兩路準備之前無法登船決戰。
3. 東風祭壇：接應觀風使，擊退哨騎，保存東風旗號。火船工坊：保全火船與引火物，擊退水寨守軍。兩路任務可任選先後，各有獨立旗標與戰鬥 checkpoint。
4. 赤壁登船口：與周瑜會合。東風與火船齊備，使決戰敵軍起始兵力降至八成；重新載入只恢復實際剩餘兵力，不重複削減。五將對戰徐晃、曹仁、張郃、魏軍槍兵與弓手。
5. 江陵營地：決戰勝利後保存一次性獎勵與結尾，回到營地整軍。第三章完成後可重新載入繼續探索與整備。

戰敗回江東水寨，損失 120 金，恢復六成五兵力與全部策略，保留兩路準備、劇情階段與實際消耗。軍議可返回當前章節的營地；江夏出口在第三章改接赤壁江岸，第二章出口保留。
